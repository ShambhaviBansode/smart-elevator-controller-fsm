# Simulation and Synthesis Results

This folder contains the simulation and RTL synthesis results of the 3-floor elevator controller designed using Verilog HDL and a Finite State Machine (FSM).

## Simulation Results

The simulation waveforms demonstrate the functional operation of the elevator controller, including:

- Reset behavior
- FSM state transitions
- Floor movement
- Elevator direction control
- Door opening
- Door closing

The simulation includes test cases for:

- Floor 1 → Floor 3
- Floor 3 → Floor 1
- Floor 1 → Floor 2

The simulation log records the execution of the test cases and the completion of the simulation.

## Synthesis Results

The synthesized RTL schematic shows the hardware structure generated from the Verilog RTL design.

The schematic images include:

- Complete synthesized RTL schematic
- Zoomed views of different sections of the synthesized design

These results provide a visual representation of the synthesized digital logic of the elevator controller.

## Tools Used

- Verilog HDL
- Xilinx Vivado 2025.2
- RTL Simulation
- RTL Synthesis
