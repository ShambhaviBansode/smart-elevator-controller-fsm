# Internship Project Report

This folder contains the complete internship project report for the 3-floor elevator controller designed using a Finite State Machine (FSM) in Verilog HDL.

The report documents the complete design and verification process of the project.

## Report Contents

The report includes:

- Aim and Objectives
- FSM Theory
- Design Methodology
- FSM State Diagram
- Verilog HDL RTL Design
- Verilog Code Explanation
- Testbench Code and Explanation
- Simulation Results
- RTL Synthesis Schematic
- Simulation Log
- Functional Verification
- Safety Conditions
- Design Assumptions
- Conclusion

## Project Title

**Smart Elevator Controller Using Finite State Machine (FSM)**

## Tools Used

- Verilog HDL
- Xilinx Vivado 2025.2
- RTL Simulation
- RTL Synthesis
